# 数据备份与合并导入

设置页的“导出数据备份”生成版本 1 的 `*.vodbox-backup.json`。包含已保存的配置快照及其原始位置、当前偏好、全部历史和收藏。历史和收藏从 SQLite 同一只读事务中读取，不复制正在写入的 db / WAL 文件，也不受历史列表 200 条显示上限影响。配置、偏好与数据库不共享事务，因此播放期间的导出不是所有资源同一时刻的严格快照。

“导入备份并合并数据”先读取并校验格式标记、版本、字段、配置身份与有效性，再自动将当前数据导出到数据目录的 `backups/before-import-*.vodbox-backup.json`，之后停止播放并导入。历史按配置 / 来源 / 媒体 / 集数合并，仅采用时间较新的记录；时间比较包含时区。收藏保留已有记录并加入缺少的记录。同 ID 配置快照及偏好被备份中的值替换。导入后刷新保存配置、历史与收藏，并应用偏好。

单文件最多 64 MiB，配置最多 1024 个，历史与收藏分别最多 100000 条。导出也应用相同限制。历史 / 收藏合并在一个数据库事务内，取消或失败会回滚；配置文件和偏好各自原子写入。不同资源之间不保证全局原子提交，磁盘故障或取消可能留下部分已导入的配置。导入前备份用于保留原始数据；当前合并导入不会自动删除新增记录，也不能作为精确回滚。遇到中断，应检查设置页状态和导入前备份后重新导入。

备份未加密，配置中的访问凭据也会包含在文件中。媒体、海报缓存、脚本文件、QuickJS / Python / Node 运行时不会打包；跨设备后本地媒体及脚本路径需要自行迁移或调整。原始配置位置在另一设备上不可访问时，仍可使用已保存的配置快照。

当前 42 项自动测试通过，备份集成测试验证 205 条历史完整导出、较新记录保留、收藏合并、配置 / 偏好恢复、无效备份在写入前拒绝，以及取消数据库合并不改变记录。文件选择、跨平台迁移与异常磁盘恢复仍需真机验收。

macOS x64 最终 Native AOT 可执行文件已实际完成配置、偏好、带进度历史与收藏的备份导出 / 读取 / 导入诊断，随后通过真实 LibVLC 四秒音频解码。此诊断也纳入六 RID 构建与安装包验证，日志：`/private/tmp/vodbox-backup-native-smoke.log`。
