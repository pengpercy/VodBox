# 桌面操作增强

媒体库海报使用 SHA-256 URL 文件名的磁盘缓存，默认容量 160 MiB，单响应最大 4 MiB，四路下载，七天后重新下载，按访问时间淘汰。仅在海报控件进入可见树时下载并后台解码到 160 像素宽缩略图；离开可见树立即取消加载并释放 Bitmap，磁盘缓存仍可复用。图片错误保留空占位，不阻断内容浏览。设计器只创建示例条目，禁止网络与缓存操作。当前海报只覆盖当前源浏览列表；聚合结果、直播 logo 与针对图片端点的请求头尚待补齐。

历史页支持按完整配置 / 内容源 / 媒体 / 集数身份删除单条，也可清空所有历史。清空时正在播放的媒体继续按原逻辑记录后续进度；无痕开关可暂停记录。SQLite v1→v2 迁移保留原有记录。

设置页支持音频及字幕延迟（±10000ms）、截图到 PNG 和 Dark / Light / System 主题。延迟保存到偏好，媒体切换后重新应用。截图等待 LibVLC SnapshotTaken 事件，再确认文件存在且非空，八秒超时报告失败。字幕、截图和主题对比度需要有画面的桌面验收，尚未宣称验证完成。

快捷键：空格暂停/继续，左右快进/退 10 秒，上下调音量 5%，M 静音/恢复，F11 切换全屏，Esc 退出全屏，PageUp/PageDown 上下集，Ctrl/⌘+O 打开媒体。F11／Esc 优先处理，不受按钮或编辑控件焦点影响；其他播放快捷键在输入框、下拉框、滑块、数字编辑器和按钮拥有焦点时，保留控件原有行为。全屏隐藏导航、地址、详情和分集，保留视频；透明播放控制栏悬浮在视频底部，不占独立高度；也可以用控制栏的全屏图标按钮退出，恢复进入前的页面和通过切换按钮进入前的窗口状态。

拖入本地媒体可播放，字幕文件载入字幕，JSON 文件按 VodBox 配置加载，HTTP/HTTPS 文本地址按地址栏选择的解析器打开；多文件目前取第一个，不建立播放队列。

早期验证记录：37 项自动测试通过，包括缓存复用 / 淘汰及跨配置历史删除隔离；严格编译零警告。新增真实 XAML 无窗口预览、明暗主题资源与海报加载取消测试。视频控件直接绑定各系统原生句柄，未使用版本或属性反射；原生画面仍需各平台验收。本机实际 HLS 播放的 150ms 原生音频延迟设置与还原已验证。大屏布局、跨平台拖放、截图、字幕和全屏交互仍待完成验收。


直播页增加频道收藏、仅看收藏、上次频道恢复。启动恢复默认关闭，可在设置中启用；上次频道以配置 / 直播源 / 频道三元身份保存，无痕时不更新。直播历史同样按频道身份记录，恢复时忽略时间轴位置。

自动线路切换默认启用：失败、结束或 30 秒没有播放进度时尝试下一地址，一轮最多尝试每条地址一次，耗尽后停止自动重试。手动换地址开始新一轮。每秒检查直播进度，暂停时不触发超时；切到点播、停止或切换配置后不再监测该频道。节目表每分钟重新计算当前节目，通过 EPG 缓存限制下载频率。该机制的策略测试通过，桌面断流及失败回退仍待端到端验收。

MacCMS 源显示年份与完结状态筛选，筛选改变会重新加载首页。单源搜索的“加载更多”保留搜索词与分页游标；脚本源可通过 params.filters 接收筛选参数，聚合搜索分页和通用筛选描述暂未实现。

全屏底部控制栏使用紧凑的当前倍速按钮，点击展开常用倍速预设和精细调节滑块，可用鼠标或键盘选择 0.25×–4×（步进 0.25×）。使用与普通窗口相同的 Rate 状态和双内核命令，退出全屏保持当前倍速。

全屏 mpv 控制栏直接叠放于视频之上；LibVLC 原生视频使用独立透明控制窗口避免原生表面遮挡按钮，两处控件共享同一个 MainViewModel。自动隐藏、跨平台视觉验收仍待实现/验证。

播放控制使用本地矢量图标：播放/暂停随状态切换，全屏/退出随窗口状态切换，停止、添加字幕和音量使用同一尺寸的图形；按钮保留 ToolTip 和 AutomationProperties.Name。倍速保留当前数字，点击展开调整。无需字体图标或额外图标包，支持编译 XAML 与 NativeAOT。
