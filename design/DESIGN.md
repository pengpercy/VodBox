# VodBox 桌面版 · 设计说明

> 基于 [FongMi/TV](https://github.com/FongMi/TV)（Android 影音应用，TVBox 系）重写的跨平台桌面应用，技术栈为 **Avalonia UI 12 + .NET 10**，目标平台 **macOS / Windows / Linux**，发布采用 **NativeAOT 编译**。本文档描述信息架构、页面结构与交互逻辑，视觉稿见同目录 HTML 原型（`index.html`）。

---

## 1. 设计理念

FongMi/TV 是 TV 遥控器/手机触屏交互：横向焦点行、屏幕键盘、菜单键弹窗。桌面版需要**彻底重排**为鼠标 + 键盘交互：

| TV/手机端 | 桌面端（VodBox） |
|---|---|
| 主页一行 Func 图标入口 | 左侧常驻导航栏（NavigationView） |
| 菜单键弹站点切换对话框 | 顶部工具栏下拉 + 独立「源管理」页 |
| 屏幕键盘搜索 | 顶部全局搜索框 + 联想下拉 |
| 详情与播放一体（小窗 400×225） | 详情页内嵌影院模式播放器 + 独立全屏播放窗口 |
| 播放控制藏在菜单键后 | 鼠标悬停浮现控制条 + 右键菜单 + 快捷键 |
| 直播三列抽屉 | 左侧频道面板（分组/频道/EPG 标签页）+ 可收起 |
| 单列滚动设置页 | 设置中心左侧分组导航 + 右侧表单卡片 |

视觉风格：**Windows 11 Fluent / Mica**。窗口背景使用 Mica 材质（`TransparencyLevelHint="Mica"` / macOS 下退化为磨砂侧栏），圆角卡片（8px）、亚克力浮层、深色主题为主（视频应用场景），同时提供浅色主题。所有页面遵循同一套栅格：左侧导航 220px（可折叠为 56px 图标栏），内容区 24px 内边距，海报网格列宽自适应（最小 160px）。

## 2. 信息架构

```
VodBox
├── 导航栏（左侧，常驻）
│   ├── 首页        推荐流 + 最近观看 + 收藏速览
│   ├── 点播        站点分类浏览（分类 Tab + 筛选 + 网格）
│   ├── 直播        频道面板 + 播放区 + EPG
│   ├── 搜索        全局搜索（聚合多站点）
│   ├── 收藏        收藏网格（点播收藏 / 直播收藏）
│   ├── 历史        观看历史（按时间分组，可续播）
│   ├── 推送        二维码 + 剪贴板推送 + 本地 HTTP 服务状态
│   └── 设置        设置中心（8 个分组）
│
├── 点播详情页（从首页/点播/搜索/收藏/历史进入）
│   ├── 头部：海报 + 元信息 + 操作按钮（播放/收藏/换源/简介）
│   ├── 内嵌播放器（影院模式，可弹出为独立窗口/全屏）
│   └── 选择器区：线路 → 清晰度 → 剧集（分段） → 快搜换站
│
├── 全屏播放窗口（独立窗口）
│   ├── 点播控制条：进度/剧集/倍速/比例/三轨/弹幕/章节/解析/循环/片头片尾
│   └── 直播控制条：频道面板/线路/EPG/回看进度/比例/音轨
│
└── 弹窗（模态）
    ├── 站点选择（含搜索/多选/网格列表切换）
    ├── 配置订阅（点播/直播/壁纸，含历史配置切换）
    ├── 字幕轨道（在线搜索字幕/本地字幕/样式设置）
    ├── 弹幕设置、倍速、缓冲、剧情简介、密码输入、更新提示
    └── 推送接收（二维码）
```

## 3. 页面详述

### 3.1 首页
- 顶栏：窗口标题区（拖拽区）+ 全局搜索框 + 时钟/日期 + 最小化/最大化/关闭（Windows 风格置右，macOS 用系统红绿灯）。
- 英雄区（Hero）：当前站点推荐第一位的大图横幅（16:7，渐变遮罩 + 片名 + 简介 + 「立即播放」「查看详情」按钮）。
- 「最近观看」横向卡带：卡片含海报、进度条（position/duration）、剧集名，右键可删除/置顶；hover 显示续播按钮。
- 「推荐」横向卡带：站点首页推荐，卡片右上角站点角标。
- 顶部站点胶囊：显示当前站点名 + 下拉切换（搜索过滤、星标常用）。

### 3.2 点播
- 顶栏：站点切换下拉 + 视图切换（网格/列表）+ 筛选按钮。
- 分类标签行（chip 横排，可滚动）：来自 `Class` 列表，选中态为主题色药丸。
- 筛选面板（可展开）：`Filter/Value` 分组（类型/地区/年份/排序），chip 多组单选。
- 海报网格：虚拟化 `ItemsRepeater`，卡片 2:3 海报 + 片名 + 备注角标（如"更新至 12 集"）+ 年份/地区；hover 浮层显示简介摘要 + 播放/收藏快捷按钮；右键菜单（播放/收藏/换源搜索/复制链接）。
- 底部分页：页码 + 加载更多（无限滚动可选）。

### 3.3 详情页（影院模式）
- 左侧 2:3 大海报（圆角 12px，带柔光投影），右侧片名（大字）+ 备注 + 元信息行（站源/年份/地区/类型）+ 导演/演员 + 剧情简介（3 行截断，点击展开弹窗）。
- 操作按钮行：主按钮「▶ 立即播放」（从上次进度续播）、次按钮「收藏」「换源」「分享/推送」。
- 选择器区（卡片分组，纵向排列）：
  1. **线路**：chip 横排（vod_play_from 拆分），选中高亮；
  2. **清晰度**：仅当该线路多清晰度时出现；
  3. **剧集**：网格按钮（每行 10 个），超过 20 集自动分段下拉（1-20 / 21-40…），支持倒序；已看集数带勾选标记，当前集高亮；
  4. **快搜换站**：同名内容在其他站点的结果 chip，一键切换站点。
- 内嵌播放器位于页面右上区域（16:9），点击进入全屏播放窗口。

### 3.4 点播全屏播放窗口
- 鼠标移动浮现控制 UI，静止 3 秒自动隐藏。
- 顶部栏：返回箭头、片名 + 当前集名、分辨率、时钟、投屏按钮、小窗模式按钮。
- 底部控制区：
  - 进度条（含缓冲进度、片头片尾区间标记、章节刻度、hover 预览时间）；
  - 按钮行：上一集/播放暂停/下一集 | 剧集列表 | 倍速（0.5–3.0，预设 + 自定义）| 画面比例 | 循环模式 | 重播 | 字幕轨（含在线字幕搜索）| 音轨 | 视频轨 | 弹幕开关+弹幕源 | 章节 | 解析线路（VIP 解析）| 播放器内核/解码 | 片头片尾设置 | 音量 | 全屏。
- 弹幕渲染层：滚动/顶部/底部弹幕，透明度与区域按设置。
- 快捷键：空格播放暂停、←→ 快退快进 5s、↑↓ 音量、F 全屏、Esc 退出、D 弹幕开关、[ ] 片头片尾、数字键选集。

### 3.5 直播
- 左侧频道面板（380px，可折叠）：
  - 顶部 Tab：分组视图 / 收藏频道 / 观看历史；
  - 分组列表（手风琴展开）→ 频道项：序号 + 台标 + 台名 + 当前节目名（来自 EPG）；
  - 搜索框过滤频道；密码分组锁定图标。
- 右侧播放区：
  - 播放器（16:9 居中，黑边自适应）；
  - 底部频道信息条：台标 + 频道号 + 频道名 + 当前节目/进度 + 下一节目；
  - EPG 节目单：横向时间轴（今日节目，可切换日期查看回看），回看节目可点击 seek。
- 直播控制条：播放/暂停、换台（上下频道）、线路切换（多源频道）、回看进度条（仅 catchup）、比例、音轨/字幕轨、直播源配置、小窗、全屏。
- 数字选台：键盘直接输入数字，屏幕中央大号显示候选。

### 3.6 搜索
- 顶部大搜索框（居中，自动聚焦），输入时实时联想（下拉建议词）。
- 默认态：搜索历史（chip + 清除）与热搜词（chip）。
- 结果态：左侧站点列表（带结果数徽标、加载状态 spinner），右侧该站结果网格；顶部显示「"关键词"在 N 个站点的结果」；站点 Tab 支持横向平铺切换（对应 CollectActivity）。
- 右键结果：播放 / 查看详情 / 收藏 / 复制链接。

### 3.7 收藏 & 历史
- 收藏：Tab 区分「点播收藏 / 直播频道」，网格卡片，hover 显示取消收藏；支持按站点筛选、按时间排序；删除模式（多选批量删除）。
- 历史：按「今天/昨天/本周/更早」时间分组，卡片含进度条与续播按钮；支持单条删除、清空全部、无痕模式提示条（无痕开启时显示横幅且不留记录）。

### 3.8 推送
- 本地 HTTP 服务状态卡（运行中/端口/局域网 IP）。
- 二维码（手机扫码打开 Web 遥控器：推送链接/远程搜索/播放控制/文件上传）。
- 「读取剪贴板」按钮 + 手动输入框：推送 URL 直接播放。

### 3.9 设置中心
左侧分组导航，右侧滚动表单卡片：

1. **源与订阅**：点播配置（URL 输入 + 历史配置下拉 + 设为首页源）、直播配置、壁纸配置、配置内公告、DoH 选择、代理；
2. **站点管理**：站点列表（可搜索/星标/隐藏/拖拽排序）、每站 searchable/changeable 开关、解析器（Parse）管理；
3. **播放**：默认内核（mpv）、硬解/软解、渲染器、缓冲区、预加载开关、后台播放、画中画（小窗）、超时换源；
4. **弹幕**：开关、文字缩放、透明度、描边、滚动区域、速度、同屏上限、行距、时间偏移、全局弹幕 API；
5. **字幕**：在线字幕 token（assrt）、默认语言、样式（字号/颜色/描边）、libass 开关、副字幕；
6. **界面**：主题（深色/浅色/跟随系统）、主题色、海报尺寸（网格密度）、图片尺寸档位、无痕模式、语言；
7. **数据**：缓存清理（显示体积）、备份（导出 history/keep/setting/config 打包）、恢复、跨设备同步（扫码/地址）；
8. **关于**：版本、检查更新、开源协议、讨论群组链接。

## 4. 技术映射（Avalonia 实现要点）

| 能力 | FongMi/TV (Android) | VodBox (Avalonia) |
|---|---|---|
| UI 框架 | Leanback + Material | Avalonia 12 + FluentTheme + Semi 主题包，自绘 Mica 背景 |
| 播放器 | ExoPlayer(Media3) / libmpv | **libmpv**（mpv.net 或 LibMpv 句柄嵌入 `NativeControlHost`/`GpuSurface`），硬软解切换 |
| 爬虫 JS | QuickJS | QuickJS.NET（原生库，AOT 友好）；Jint 需验证 AOT 兼容性，反射型解释器有裁剪风险 |
| 爬虫 Python | Chaquopy | 子进程 CPython（内嵌运行时随包分发，与 AOT 主进程解耦） |
| 爬虫 Jar(csp_) | DexClassLoader | 适配层：优先提示"该源不支持桌面"，长期可移植为 .NET 插件（C# 脚本） |
| WebView 嗅探 | Android WebView | WebView2 (Win) / WebKitGTK (Linux) / WKWebView (macOS)，经 `WebViewControl` 抽象 |
| 本地 DB | Room (SQLite) | SQLite（Microsoft.Data.Sqlite，AOT 友好）+ 手写仓储或 Dapper；**避免 EF Core**（重度反射，AOT 需额外配置且体积大） |
| 本地 HTTP | NanoHTTPD | Kestrel 自宿主 minimal API（/proxy /cache /action /media /upload 契约不变；AOT 下用 source-gen JSON 序列化） |
| 弹幕 | 自研 DanmakuFlameMaster 系 | SkiaSharp 自绘层（滚动/顶部/底部，时间轴同步） |
| DLNA 投屏 | cling 系 | 可选：SSDP 发现 + AVTransport（二期） |
| 配置解密 | AES-CBC + base64 链 | System.Security.Cryptography 复刻同一解密链 |
| 跨设备同步 | /action sync | 保留同一协议，兼容手机端互传 |
| JSON 序列化 | Gson | System.Text.Json + **JsonSourceGenerationOptions**（AOT 必须，禁用运行时反射序列化） |

**NativeAOT 发布约束（必须在架构期遵守，返工成本极高）**：

1. **csproj 配置**：`<PublishAot>true</PublishAot>`，每目标 RID 独立发布（`win-x64` / `osx-x64` / `osx-arm64` / `linux-x64` / `linux-arm64`），三平台各自出包； trimming 自动开启。
2. **禁用/规避反射依赖**：不使用 `Activator.CreateInstance` 动态插件加载、不依赖 `Newtonsoft.Json`、不使用 `Expression.Compile` 热路径；DI 容器用 `Microsoft.Extensions.DependencyInjection` 的 source-generator 模式或手写组合根。
3. **爬虫 JS 引擎**：优先 QuickJS.NET（P/Invoke 原生库，天然 AOT 安全）；Jint 解释器依赖反射树，启用前必须用 `RD.xml` 指令验证，不通过则弃用。
4. **XAML 编译**：Avalonia XAML 本身在编译期生成 IL，AOT 天然兼容；但禁用运行时 `RuntimeTypeModel`/动态 `DataTemplate`，所有模板静态声明。
5. **libmpv 绑定**：P/Invoke 声明 + `[LibraryImport]` source generator（`DisableRuntimeMarshalling` 场景注意字符串编组）。
6. **体积目标**：单平台发布含 libmpv/QuickJS 原生库控制在 ~80MB 内（AOT 裁剪后托管体预计 30–40MB + 原生依赖）。
7. **启动性能**：AOT 冷启动 < 300ms 目标（对应桌面应用即点即开体验）。

**Mica 落地**：Windows 使用 `WindowTransparencyLevelHint="Mica"` + `ExtendClientAreaToDecorationsHint`；macOS 使用 `NSVisualEffectView`（侧栏磨砂）；Linux 退化为半透明 + 模糊（或纯色，取决于合成器）。三平台共用同一套 XAML 样式与资源字典。

## 5. 设计稿文件

同目录 `index.html` 为高保真原型（Mica 深色主题），包含 8 个页面画板：首页 / 点播 / 详情 / 点播播放 / 直播 / 搜索 / 收藏历史 / 设置中心。浏览器打开即可翻阅。
